# Supabase auth email templates

Paste each file into Supabase → Authentication → Emails → Templates.

- `confirm-signup.html` — subject: **Confirm your email · Confirma tu email**
- `reset-password.html` — subject: **Reset your password · Cambia tu contraseña**
- `magic-link.html` — subject: **Your CampusSwap login link · Tu enlace para entrar**
- `change-email.html` — subject: **Confirm your new email · Confirma tu nuevo email**
